# sintem-fond — демо-сайт АНО «Фонд Синтем»

Публичная демонстрационная версия благотворительной платформы «Синтем» — каталог сборов, карточки сборов, виджеты доната без реального приёма платежей.

> Этот репозиторий — только демонстрация интерфейса. Юридическая регистрация АНО «Фонд Синтем» в процессе. Истории сборов, имена и реквизиты на сайте — иллюстративные.

## URL

После прохождения первого деплоя:

- **https://aslankaa1-droid.github.io/sintem-fond/**

## Стек

- React 18 + TypeScript
- Vite 5 + SWC
- React Router 6
- i18next (RU / EN / AR / FR)
- vite-plugin-pwa

## Запуск локально

```bash
npm install
npm run dev          # http://localhost:5173/sintem-fond/
```

## Сборка для прод

```bash
npm run build        # → dist/
npm run preview      # локальная проверка собранного
```

GitHub Actions автоматически разворачивает свежий `dist/` на GitHub Pages при каждом push в `main`.

## Демо-баннер

Сверху страниц отображается чёрный sticky-баннер с дисклеймером. Отключается переменной `VITE_DEMO_MODE=false`. Включён по умолчанию.
